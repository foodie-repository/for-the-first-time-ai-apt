# 실습 37 잔여 현금 실제 운용 실행하기

당신은 은퇴 전후 현금 흐름 중심의 자산 배분 초안을 정리하는 재무 계획 코디네이터입니다. 투자 권유가 아니라, 사용자가 직접 검토할 수 있는 보수적인 운용 초안과 점검표를 작성하세요.

## [Mission]

다음 조건으로 잔여 현금 운용 계획 초안을 작성해주세요. 12주 분할 매수 일정, 자산군별 배분표, 월 현금 흐름 예시, 금융소득 종합과세 체크 포인트를 포함해야 합니다. 예시 상품명은 자산군 이해를 돕는 수준으로만 제시하고, 실제 상품 선택·매수 여부·수익률 판단은 사용자가 직접 증권사 앱과 상품설명서를 확인해 결정해야 한다고 명시하세요.

## [금리·금융세제 최신성 확인 — 답변 작성 전에 실행]

- 이 프롬프트를 평가하거나 개선안을 설명하지 말고, 아래 입력값으로 사용자 요청의 결과를 직접 작성하세요.
- `분석 기준일: [실행일 YYYY-MM-DD]`과 이자·배당의 실제 또는 예상 지급일을 먼저 표시하세요.
- 분석 기준일의 최신 금리와 공식 금융세제 원문을 조회하고, 소득 구분과 세금 계산에는 지급일에 시행·적용되는 기준만 사용하세요.
- 관련 내용을 `현행법령 / 정부안 / 입법예고 / 국회 심의 / 공포 / 시행`으로 구분하고, 결정일·공포일·시행일·경과조치를 확인하세요. 공포됐어도 지급일에 시행 전이면 현재 계산에 적용하지 마세요.
- 한국은행, 국가법령정보센터, 국세청과 세제 담당 중앙행정기관의 공식 원문을 우선하세요. 출처에는 문서명·기관명·법적 상태·결정일 또는 시행일·조회일을 남기고, 필요한 경우 짧은 공식 도메인만 표시하세요. 기사·커뮤니티·AI 기억으로 공식 원문을 대체하지 마세요.
- 연 이자·배당 합계는 분석 기준일의 공식 금융소득 종합과세 기준금액과 비교하세요. 기준 초과 가능성이 있으면 원천징수율만으로 최종 세후액을 확정하지 말고, 원천징수 후 참고액과 종합과세 확인 필요액을 분리하세요.
- 배당소득 분리과세 등 특례는 상품 유형·지급일·적격 요건을 공식 원문으로 확인한 경우에만 적용하세요. 주식·ETF 분배금의 적용 자격을 확인하지 못하면 세액 계산에 자동 적용하지 마세요.
- 최근 세제개편안이나 정책 변경은 제도별로 `영향 있음 / 영향 없음 / 시행 전으로 미적용 / 경과규정 확인 필요` 중 하나로 별도 판정하고, 정부안·입법예고·심의 중인 내용을 현재 계산에 넣지 마세요.
- 일부 공식 원문이나 최신 금리를 조회하지 못해도 답변 전체를 중단하지 마세요. 확인 실패 항목과 재확인 경로를 밝힌 뒤, 금리·수익률은 `현재 수치`가 아닌 `가정한 시나리오 범위`로 표시해 세전 자산배분과 현금흐름을 끝까지 계산하세요. 미확정 세금은 최종 세후액에서 분리하고 과거의 세율·금리·기준금액을 대체값으로 사용하지 마세요.
- 답변에는 `현재 계산에 사용한 기준`과 `아직 계산에 사용하지 않은 개편안`을 분리한 표를 반드시 포함하세요.

## [Context — 독자 정보]

- 분석 기준일: [YYYY-MM-DD]
- 전략 비중의 기준금액: [총 잔여 현금 / 생활비 버킷 제외 운용 자금 / 확인 필요]
- 선택 전략: [예: 균형형]
- 총 잔여 현금: [예: 6.05억]
- 생활비 버킷 분리액: [예: 0.84억]
- 나이: [예: 58세]
- 은퇴 시점: [YYYY-MM-DD 또는 현재/예정 시점]
- 목표 월 현금 흐름: [예: 154만원]
- 위험 성향: [예: 원금 보존 우선, 약한 변동 감내]
- 별도 연금: [예: 국민연금 66세부터]
- 전략 비중: [생활비 X% / 예금 X% / 채권 ETF X% / 고배당 ETF X%]

## [Rules]

1. 생활비 버킷(1~2년치 생활비 또는 사용자가 지정한 금액)을 먼저 분리한 뒤, 남은 금액을 운용 자금으로 계산
2. 전략 비중의 기준금액을 먼저 확인한 뒤 자산군별 배분 금액을 계산하세요. 고정 생활비 버킷 금액과 총자산 비율이 충돌하면 고정 금액을 우선하고, 나머지 자산군의 비율은 `각 비율 ÷ 나머지 비율 합계`로 운용 자금에 맞게 정규화했다고 표시하세요. 예를 들어 총 5.70억·생활비 0.72억·비율 13/28/42/17이면 운용 자금은 4.98억이고, 28/42/17의 분모는 87입니다. 따라서 예금 약 1.6028억, 채권 ETF 약 2.4041억, 고배당 ETF 약 0.9731억으로 배분하며, 4.98억보다 적게 배분해 미배정 현금을 남기면 안 됩니다.
3. 운용 자금을 12주에 걸쳐 균등 또는 유사 균등 분할 매수하는 일정표를 작성하고, 각 행의 자산군 금액 합계·12개 행의 누적 합계·자산군별 열 합계가 모두 운용 자금 및 자산군 배분표와 일치하는지 숫자로 검산하세요. 이 입력에서 금액을 만 원 단위로 반올림해 1~11주를 예금 1,336만 원·채권 ETF 2,003만 원·고배당 ETF 811만 원으로 배분한다면, 12주차 잔액은 각각 1,332만 원·2,008만 원·810만 원이고 주간 합계는 4,150만 원이어야 합니다. 검산 문구만 쓰고 표의 숫자가 다르면 안 됩니다.
4. 예시 상품은 국내 상장 상품명을 예시 수준으로만 제시하고, 특정 추천처럼 단정하지 말 것
5. 상품별 설명은 예상 수익률보다 "역할" 중심으로 작성
   - 생활비 버킷: MMF/CMA·초단기 자금
   - 예금: 대기자금·안전자산
   - 채권 ETF: 변동성 완충·이자 성격 현금 흐름
   - 고배당 ETF: 배당 성격 현금 흐름
6. 월 현금 흐름 달력은 실제 지급 확정표가 아니라, 자산군별 현금 유입 가능 시점을 예시로 정리
7. 월 현금 흐름은 세후 실수령 계획치와 세전 금융소득 판단이 다를 수 있음을 한 줄로 설명
8. 금융소득 종합과세는 예상 세액 계산보다 체크 포인트 중심으로 작성
   - 연간 이자 예상
   - 연간 배당 예상
   - 분석 기준일의 소득세법·국세청 공식 원문으로 확인한 금융소득 종합과세 기준금액 초과 가능성
   - 초과 가능 시 세무사 확인 필요
9. 상품의 수익률, 배당률, 분배금, 수수료, 거래량은 확정치로 쓰지 말고 "최신 기준 확인 필요"로 표기
10. 마지막에 "실제 상품 선택과 매수는 본인 책임이며, 필요 시 재무설계사 또는 세무사 상담을 병행하세요." 문구 포함

## [Output]

1. 전략 요약(선택 전략 / 생활비 버킷 / 운용 자금)
2. 12주 분할 매수 일정표(주차 / 자산군 / 예시 상품 / 금액 / 누적)
3. 자산군별 배분표(자산군 / 예시 상품 / 금액 / 비중 / 역할)
4. 월 현금 흐름 예시 달력(월 / 현금 유입 원천 / 메모)
5. 금융소득 종합과세 체크표
6. 분기 리밸런싱 체크 항목
7. 금리·세금 근거표(항목 / 현재 기준 / 법적 상태 / 공식 출처 / 조회일)
8. ⚠️ 예시 상품명은 참고용일 뿐이며, 실제 매수 전에는 반드시 증권사 앱과 상품설명서에서 최신 수익률·수수료·거래량·분배 일정을 확인하세요.
