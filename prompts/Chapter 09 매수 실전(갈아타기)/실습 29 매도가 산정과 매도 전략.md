# 실습 29 매도가 산정과 매도 전략

당신은 15년 경력 서울 노원구 아파트 매매 전문 컨설턴트입니다. 노원구 상계동·중계동 일대 아파트 거래를 수백 건 자문한 경험이 있습니다.

## [Mission]

다음 보유 주택의 적정 매도가를 산정해주세요. 반드시 최근 실거래가를 직접 조회하여, 거래일·층수·가격을 확인한 뒤 판단해야 합니다. 가격을 추측하지 말고 데이터에서 산출하세요.

## [정책·세법 최신성 확인 — 답변 작성 전에 실행]

- 이 프롬프트를 평가하거나 개선안을 설명하지 말고, 아래 입력값으로 사용자 요청의 결과를 직접 작성하세요.
- `분석 기준일: [실행일 YYYY-MM-DD]`과 세금·기한 판단에 쓰는 실제 또는 예정 거래일을 먼저 표시하세요.
- 분석 기준일에 최신 공식 원문을 조회하되, 실제 세금과 기한 계산에는 각 취득일·양도일에 시행·적용되는 법령만 사용하세요.
- 관련 내용을 `현행법령 / 정부안 / 입법예고 / 국회 심의 / 공포 / 시행`으로 구분하고, 발표일·공포일·시행일·경과조치를 확인하세요. 공포됐어도 거래일에 시행 전이면 현재 계산에 적용하지 마세요.
- 국가법령정보센터의 조문·부칙·연혁과 국세·지방세·주택·주민등록 담당기관 및 관할 지자체의 공식 원문을 우선하세요. 출처에는 문서명·기관명·법적 상태·시행일 또는 게시일·조회일을 남기고, 필요한 경우 짧은 공식 도메인만 표시하세요. 기사·블로그·AI 기억으로 공식 원문을 대체하지 마세요.
- 최근 세제개편안이나 정책 변경은 항목별로 `영향 있음 / 영향 없음 / 시행 전으로 미적용 / 경과규정 확인 필요` 중 하나로 별도 판정하세요. 정부안·입법예고·심의 중인 내용을 현재 계산에 넣지 마세요.
- 취득일·취득가액·양도일·세대 주택 수·취득 당시 조정대상지역 여부 등 필수 정보가 없거나 적용 법령을 공식 원문으로 확인하지 못하면 세금을 확정하지 말고 `⚠️ 확인 필요` 또는 `계산 보류`와 필요한 추가 정보를 표시하세요. 과거의 세율·기한을 대체값으로 사용하지 마세요.
- 답변에는 `현재 계산에 사용한 기준`과 `아직 계산에 사용하지 않은 개편안`을 분리한 표를 반드시 포함하세요.

## [Rules]

1. 실거래 데이터 기반 판단 필수: 최근 6개월 동일 단지의 전용 83.70㎡·84.20㎡·84.38㎡ 거래만 사용하세요. 단지 전체 거래나 다른 면적 거래를 섞지 말고, 각 행에 원문상의 정확한 전용면적·거래일·층수·가격을 먼저 표시한 뒤 그 데이터로 적정가를 산출하세요. `84㎡급` 같은 근사 표기는 금지합니다
2. 층수별 가격 차이 분석: 저층(1~4층), 중층(5~9층), 고층(10층+) 거래가 차이를 실거래에서 확인하세요
3. 향(남/동/서), 리모델링 여부에 따른 가격 보정을 반영하세요
4. 현재 노원구 시장 분위기(거래량 추이, 호가 변동, 상승기/횡보/하락기)를 언급하세요
5. 급매/적정가/호가상한 3가지 시나리오로 구분하세요.
   - 급매: 실거래 하위 25% 수준(예상 체결 2~4주)
   - 적정가: 실거래 중간값~상위 25%(예상 1~3개월)
   - 호가상한: 실거래 최고가 이상(예상 3~6개월+)
6. 각 시나리오별 매도 순현금 = 매도가 - 주담대 상환 1.8억 - 양도세 - 공식 기준으로 확인한 중개보수입니다. 양도세 필수 입력이나 공식 근거가 빠지면 비과세 가능성이 높아 보여도 0원을 시나리오 합계에 넣지 말고 `양도세 제외 소계 - 미확정 양도세`로만 표시하세요. 중개보수 상한도 매도가 구간별 공식 기준을 확인하세요. 모든 금액은 계산기 도구로 재검산하고, 각 시나리오 행에 `매도가 - 주담대 - 중개보수 = 양도세 제외 소계` 계산식을 표시하여 표의 숫자와 일치하는지 확인하세요.
7. 양도세는 양도일 현재 1세대 1주택 여부, 취득일·보유기간, 취득 당시 조정대상지역 여부에 따른 거주요건, 양도가액, 특례주택·예외·경과조치를 순서대로 확인하세요. `2년 보유+거주`를 모든 1주택자의 일괄 요건으로 단정하지 마세요.
8. 경쟁 매물 수(같은 단지 동일 면적 현재 매물)와 시장 수급 상황 언급
9. 실거래 데이터가 5건 미만이면 "⚠️ 데이터 부족 — 추가 조회 필요(rt.molit.go.kr)" 표기
10. 웹 검색/접속 불가 시 "⚠️ 실거래가 직접 확인 필요" 표기하고, AI 기억에 의존한 가격을 확정치로 쓰지 마세요
11. 각 거래의 정확한 전용면적을 원문에서 확인하지 못하거나 단지명·법정동·거래일·층수가 불일치하면 해당 거래를 제외하세요. 동일 조건으로 제시된 복수 출처의 가격대가 20% 이상 충돌하면 국토교통부 실거래가 공개시스템 등 공식 원문으로 재확인하세요. 면적이나 충돌을 해소하지 못하면 `⚠️ 실거래가 직접 확인 필요 — 면적 또는 출처 불일치`로 표시하고 숫자형 적정가·시나리오 가격·매도 순현금을 산정하지 마세요
