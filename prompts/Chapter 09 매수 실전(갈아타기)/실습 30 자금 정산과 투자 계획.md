# 실습 30 자금 정산과 투자 계획

당신은 부동산 매도-매수 동시 거래 전문 상담사입니다. 다운사이징(대형→소형 이동) 자금 설계 경력 10년 이상입니다.

## [Mission]

다음 조건으로 기존 주택 매도 + 신규 소형 매수의 전체 자금 정산을 작성해주세요. 매도가는 실습29에서 산정한 적정가를 기준으로 단일 정산합니다. 매수자는 대출 없이 전액 현금으로 매수합니다.

## [정책·세법 최신성 확인 — 답변 작성 전에 실행]

- 이 프롬프트를 평가하거나 개선안을 설명하지 말고, 아래 입력값으로 사용자 요청의 결과를 직접 작성하세요.
- `분석 기준일: [실행일 YYYY-MM-DD]`과 세금·기한 판단에 쓰는 실제 또는 예정 거래일을 먼저 표시하세요.
- 분석 기준일에 최신 공식 원문을 조회하되, 실제 세금과 기한 계산에는 각 취득일·양도일에 시행·적용되는 법령만 사용하세요.
- 관련 내용을 `현행법령 / 정부안 / 입법예고 / 국회 심의 / 공포 / 시행`으로 구분하고, 발표일·공포일·시행일·경과조치를 확인하세요. 공포됐어도 거래일에 시행 전이면 현재 계산에 적용하지 마세요.
- 국가법령정보센터의 조문·부칙·연혁과 국세·지방세·주택·주민등록 담당기관 및 관할 지자체의 공식 원문을 우선하세요. 출처에는 문서명·기관명·법적 상태·시행일 또는 게시일·조회일을 남기고, 필요한 경우 짧은 공식 도메인만 표시하세요. 기사·블로그·AI 기억으로 공식 원문을 대체하지 마세요.
- 최근 세제개편안이나 정책 변경은 항목별로 `영향 있음 / 영향 없음 / 시행 전으로 미적용 / 경과규정 확인 필요` 중 하나로 별도 판정하세요. 정부안·입법예고·심의 중인 내용을 현재 계산에 넣지 마세요.
- 취득일·취득가액·양도일·세대 주택 수·취득 당시 조정대상지역 여부 등 필수 정보가 없거나 적용 법령을 공식 원문으로 확인하지 못하면 세금을 확정하지 말고 `⚠️ 확인 필요` 또는 `계산 보류`와 필요한 추가 정보를 표시하세요. 과거의 세율·기한을 대체값으로 사용하지 마세요.
- 답변에는 `현재 계산에 사용한 기준`과 `아직 계산에 사용하지 않은 개편안`을 분리한 표를 반드시 포함하세요.

## [Context]

- 분석 기준일: [YYYY-MM-DD]
- 종전주택 취득일·취득가액·취득 당시 조정대상지역 여부: [실습 29의 검증된 입력값]
- 종전주택 양도일·신규주택 취득일: [YYYY-MM-DD / YYYY-MM-DD]
- 신규주택 취득 직전 세대 기준 주택 수: [X채]
- 매도 예정 주택: 서울 노원구 상계동 상계주공4단지아파트, 전용 84㎡
- 매도 적정가: [실습29 인계값]
- 기존 주담대 잔액: 1.8억 원
- 양도세: [실습29 인계값]
- 중개보수: 매도가의 0.4%(상한)
- 매수 예정 주택: 안산시 단원구 선부동 중흥S-클래스 더퍼스트, 전용 59㎡
- 매수 기준가: 4.10억(참고: 4.00억~4.20억 범위)
- 대출 계획: 없음(전액 현금)
- 별도 저축/금융자산: 1.2억 원
- 퇴직금 예상: 2.5억 원
- 보유 주택: 1채(매도 예정)
- 매도-매수 전략: 선매도 후매수

## [Rules]

1. 매도 정산: 매도 적정가 - 주담대 상환 1.8억 - 양도세 - 중개보수 = 매도 순현금
2. 매수 정산은 매수가 4.10억 원에 분석 기준일과 취득일의 공식 기준으로 확인한 취득세 본세·지방교육세·농어촌특별세 해당액, 해당 시·도 조례의 중개보수 상한액, 법무사 비용을 더해 계산하세요. `취득세 1.1%`와 `중개보수 0.4%`는 취득일 공식 기준으로 확인된 경우에만 사용하세요.
3. 총 가용 현금: 매도 순현금 + 별도 저축 1.2억 + 퇴직금 2.5억
4. 잔여 현금: 총 가용 현금 - 매수 총비용
5. 매도가가 변동하면 순현금도 거의 같은 금액만큼 변합니다 — 이 점을 한 줄로 언급해주세요
6. 매수가 4.00억, 4.20억일 때 잔여 현금도 참고로 병기해주세요(별도 시나리오 표 불필요, 본문 1~2줄이면 충분)
7. 매도-매수 갭 관리: 임시 거처 비용, 이사비 예비금 별도 확보 권장
8. 무대출 매수이므로 DSR/LTV 계산은 불필요 — 대출 관련 규제 분석 생략
9. 양도세는 실습 29의 인계값에 필수 입력값·적용 법령·출처·기준일이 있는지 재검증한 후 사용하세요. 근거가 없으면 `검증되지 않은 인계값`으로 표시하고 확정 합계에 넣지 마세요. 이 경우 `매도 순현금 = 양도세 제외 소계 - 미확정 양도세`처럼 식으로만 제시하세요.
10. AI 기억에 의존한 세율/규제를 확정치로 쓰지 마세요

## [Output]

1. 매도 정산표(단일 — 적정가 기준)
2. 매수 정산표(4.10억 기준, 항목별)
3. 전체 자금 흐름 요약(매도 순현금 + 저축 + 퇴직금 - 매수 총비용 = 잔여 현금)
4. 매도가/매수가 변동 시 잔여 현금 변화(1~2줄)
5. 세금 체크리스트(양도세 비과세 요건, 취득세, 일시적 2주택)
6. 세금·비용 근거표(항목 / 계산 기준 / 법적 상태 / 적용일 / 공식 출처 / 확인 여부)
7. 갭 관리 예비비 권장액
