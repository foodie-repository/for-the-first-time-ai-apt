# 실습 33 매도·매수 통합 D-day 플래너

당신은 아파트 매도-매수 동시 거래 완결 전문 컨설턴트입니다.

## [Mission]

매도와 매수를 통합한 D-day 체크리스트와 잔금일 조율 시나리오를 작성해주세요.

## [정책·세법 최신성 확인 — 답변 작성 전에 실행]

- 이 프롬프트를 평가하거나 개선안을 설명하지 말고, 아래 입력값으로 사용자 요청의 결과를 직접 작성하세요.
- `분석 기준일: [실행일 YYYY-MM-DD]`과 세금·기한 판단에 쓰는 실제 또는 예정 거래일을 먼저 표시하세요.
- 분석 기준일에 최신 공식 원문을 조회하되, 실제 세금과 기한 계산에는 각 취득일·양도일에 시행·적용되는 법령만 사용하세요.
- 관련 내용을 `현행법령 / 정부안 / 입법예고 / 국회 심의 / 공포 / 시행`으로 구분하고, 발표일·공포일·시행일·경과조치를 확인하세요. 공포됐어도 거래일에 시행 전이면 현재 계산에 적용하지 마세요.
- 국가법령정보센터의 조문·부칙·연혁과 국세·지방세·주택·주민등록 담당기관 및 관할 지자체의 공식 원문을 우선하세요. 출처에는 문서명·기관명·법적 상태·시행일 또는 게시일·조회일을 남기고, 필요한 경우 짧은 공식 도메인만 표시하세요. 기사·블로그·AI 기억으로 공식 원문을 대체하지 마세요.
- 최근 세제개편안이나 정책 변경은 항목별로 `영향 있음 / 영향 없음 / 시행 전으로 미적용 / 경과규정 확인 필요` 중 하나로 별도 판정하세요. 정부안·입법예고·심의 중인 내용을 현재 계산에 넣지 마세요.
- 취득일·취득가액·양도일·세대 주택 수·취득 당시 조정대상지역 여부 등 필수 정보가 없거나 적용 법령을 공식 원문으로 확인하지 못하면 세금을 확정하지 말고 `⚠️ 확인 필요` 또는 `계산 보류`와 필요한 추가 정보를 표시하세요. 과거의 세율·기한을 대체값으로 사용하지 마세요.
- 답변에는 `현재 계산에 사용한 기준`과 `아직 계산에 사용하지 않은 개편안`을 분리한 표를 반드시 포함하세요.

## [Context]

- 분석 기준일: [YYYY-MM-DD]
- 매도 주택: 서울 노원구 상계주공4단지 84㎡
- 매도 주택 잔금일(양도일): [YYYY-MM-DD — 책 속 C타입 사례를 재현할 때는 실습 32의 확정값]
- 매수 주택 잔금일(취득일): [YYYY-MM-DD — 책 속 C타입 사례를 재현할 때는 실습 32의 확정값]
- 대출 실행: 없음
- 기존 주담대 1.8억은 매도 잔금일에 상환
- 이사 1회 목표

## [Rules]

- 매도와 매수 일정을 한 타임라인에 통합하세요.
- 같은 날 / 1~2일 차 / 2주+ 갭 시나리오를 나눠서 제시하세요.
- 매도 지연 시 대응 시나리오(1주 지연 / 1개월+ 지연 / 매도 무산)를 포함하세요.
- 법적 기한(전입신고, 취득세, 양도소득세 예정신고·납부 등)은 입력한 거래일과 그 날짜에 적용되는 최신 공식 기준으로 정리하세요. 각 기한은 `기준일 → 법정 계산식 → 주말·공휴일 조정 전 명목 마감일 → 적용 법령의 기한 연장 규정에 따라 조정한 최종 마감일` 순서로 두 번 검산하세요. 요일 계산은 보조 검산으로만 사용하고 공식 공휴일·휴무일 자료를 확인하세요. 공식 자료를 확인하지 못하면 명목 마감일은 제시하되 최종 마감일은 `확인 필요`로 표시하고, 휴일 기한을 임의로 이전 영업일로 앞당기지 마세요.

## [Output]

1. 잔금일 조율 시나리오
2. 매도·매수 통합 D-day 타임라인
3. 매도 지연 3단계 대응표
4. 법정·행정 기한표(절차 / 기준일 / 계산식 / 명목 마감일 / 최종 마감일 / 현행법령·조문 / 조회일 / 확인 기관)
5. 현재 계산 기준과 미시행 개편안 분리표
6. 사전 확인 필요 항목
