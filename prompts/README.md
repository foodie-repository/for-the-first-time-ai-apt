# Markdown 프롬프트

책에 수록된 실습 38개와 AI 맞춤 지침 템플릿 1개를 Markdown으로 정리한 사본입니다. 기존 챕터명·파일명과 프롬프트 문구·변수·예시를 유지하고, 제목·구역·목록·표의 서식을 정리했습니다. 저장소 루트의 `Chapter NN …/` 폴더에 있는 `.txt` 원본은 그대로 보존합니다.

각 파일의 제목 아래 본문을 복사하여 AI에 붙여 넣으세요. 예시와 사용자 입력 폼이 함께 들어 있는 실습은 원문의 안내에 따라 단계별로 사용합니다. 원본과 Markdown 사본은 자동으로 동기화되지 않으므로, 이후 내용을 수정할 때는 수정 대상을 명확히 구분하세요.

이용 조건은 [LICENSE](../LICENSE)를, 변수와 실행 시점 확인 원칙은 [변수 표기 규칙](../docs/변수표기_규칙.md)과 [시점중립 안내](../docs/시점중립_안내.md)를 따릅니다.
