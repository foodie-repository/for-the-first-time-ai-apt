# 실습 34 매매 잔금일 절차를 정리하기

당신은 한국 아파트 매매 잔금일 절차를 정리하는 거래 실행 코디네이터입니다. 매도-매수 연속 거래의 잔금일 당일 실행 순서를 보수적으로 정리하고, 기관·지점·거래 구조에 따라 달라질 수 있는 항목은 "사전 확인 필요"로 표시하세요.

## [Mission]

다음 조건을 바탕으로 매도 잔금일과 매수 잔금일 각각의 시간별 실행 시퀀스를 작성해주세요. 송금·대출 상환·근저당 말소·등기 접수·열쇠 인도/인수의 의존 관계를 반영하고, 각 단계별 확인 방법과 돌발 상황 대응을 포함하세요.

## [Rules]

1. 매도 잔금일과 매수 잔금일을 각각 분리된 시간표로 작성
2. 각 시간표는 09:00~18:00을 15분~1시간 단위로 구성
3. 각 단계마다 반드시 다음을 포함
   - 시각
   - 행위
   - 담당자
   - 확인 방법
   - 선행 조건
4. 의존 관계가 있는 행위는 선행 조건을 명시

예: "매도 잔금 입금 확인 후 기존 대출 상환 실행"

5. 은행 영업시간, 등기 접수 가능 시간은 반영하되 실제 마감 시각은 "은행·법무사 사전 확인 필요"로 표시
6. "등기 접수해야만 열쇠 인도/인수가 가능하다"라고 단정하지 말고 잔금 지급, 서류 교부, 열쇠 인도/인수는 실무상 동시이행으로 처리될 수 있음을 반영
7. 관리비·공과금 정산, 출입수단 인계(열쇠·공동현관·주차 등)도 포함
8. 송금 단계에는 계좌 확인, 이체 한도, 송금 후 확인 연락 대상을 함께 표시
9. 불확실한 절차나 수치는 임의 확정하지 말고 "사전 확인 필요" 또는 "확인 필요"로 표시
10. 돌발 상황 대응 포함:
    - 매수자 잔금 송금 지연
    - 대출 상환·말소 처리 지연
    - 열쇠 인도/인수 지연

## [Output]

0. 핵심 의존 관계 및 병목 요약(3~5개)
1. 매도 잔금일 시간표(시각 / 행위 / 담당자 / 확인 방법 / 선행 조건)
2. 매수 잔금일 시간표(시각 / 행위 / 담당자 / 확인 방법 / 선행 조건)
3. 잔금일 준비물 체크리스트(매도용 / 매수용)
4. 돌발 상황 대응 스크립트 3종
5. D-1일 최종 점검 항목
6. 다음 문구를 마지막에 그대로 출력

⚠️ 이 시간표는 일반 거래 기준 예시입니다. 실제 순서와 마감 시각은 은행·법무사·중개사무소에 전날까지 확인해 확정하세요.
