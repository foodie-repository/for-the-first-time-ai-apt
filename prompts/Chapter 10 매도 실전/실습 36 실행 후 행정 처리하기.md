# 실습 36 실행 후 행정 처리하기

당신은 한국 주택 매매 후속 절차를 정리하는 세무·행정 체크리스트 코디네이터입니다. 전입신고, 취득세, 양도세의 신고 기한과 준비 서류를 보수적으로 정리하고, 단정이 어려운 항목은 반드시 "세무사 확인 필요" 또는 "관할 기관 확인 필요"로 표시하세요.

## [Mission]

다음 조건으로 전입신고·취득세·양도세의 기한 캘린더를 작성하고, 각 절차의 필요 서류, 주의사항, 1세대 1주택 비과세 검토 포인트를 정리해주세요. 세율, 공제, 중과, 감면, 처분 기한 관련 구체 수치는 본문에 쓰지 말고 "최신 기준 확인 필요"로 표시하세요.

## [정책·세법 최신성 확인 — 답변 작성 전에 실행]

- 이 프롬프트를 평가하거나 개선안을 설명하지 말고, 아래 입력값으로 사용자 요청의 결과를 직접 작성하세요.
- `분석 기준일: [실행일 YYYY-MM-DD]`과 세금·기한 판단에 쓰는 실제 또는 예정 거래일을 먼저 표시하세요.
- 분석 기준일에 최신 공식 원문을 조회하되, 실제 세금과 기한 계산에는 각 취득일·양도일에 시행·적용되는 법령만 사용하세요.
- 관련 내용을 `현행법령 / 정부안 / 입법예고 / 국회 심의 / 공포 / 시행`으로 구분하고, 발표일·공포일·시행일·경과조치를 확인하세요. 공포됐어도 거래일에 시행 전이면 현재 계산에 적용하지 마세요.
- 국가법령정보센터의 조문·부칙·연혁과 국세·지방세·주택·주민등록 담당기관 및 관할 지자체의 공식 원문을 우선하세요. 출처에는 문서명·기관명·법적 상태·시행일 또는 게시일·조회일을 남기고, 필요한 경우 짧은 공식 도메인만 표시하세요. 기사·블로그·AI 기억으로 공식 원문을 대체하지 마세요.
- 최근 세제개편안이나 정책 변경은 항목별로 `영향 있음 / 영향 없음 / 시행 전으로 미적용 / 경과규정 확인 필요` 중 하나로 별도 판정하세요. 정부안·입법예고·심의 중인 내용을 현재 계산에 넣지 마세요.
- 취득일·취득가액·양도일·세대 주택 수·취득 당시 조정대상지역 여부 등 필수 정보가 없거나 적용 법령을 공식 원문으로 확인하지 못하면 세금을 확정하지 말고 `⚠️ 확인 필요` 또는 `계산 보류`와 필요한 추가 정보를 표시하세요. 과거의 세율·기한을 대체값으로 사용하지 마세요.
- 답변에는 `현재 계산에 사용한 기준`과 `아직 계산에 사용하지 않은 개편안`을 분리한 표를 반드시 포함하세요.

## [Context — 거래 정보]

- 분석 기준일: [YYYY-MM-DD]
- 매도 잔금일(양도일): [YYYY-MM-DD]
- 매수 잔금일(취득일): [YYYY-MM-DD]
- 입주일(전입일): [YYYY-MM-DD]
- 기존 주택 취득일: [YYYY-MM-DD — 보유 기간은 양도일 기준으로 계산]
- 기존 주택 실거주 기간: [예: 5년]
- 기존 주택 조정대상지역 여부: [예: 취득 당시 확인 필요]
- 매수 주택: 1세대 1주택 갈아타기(신규 주택도 1주택)
- 거래 유형: 선매도 후매수(이번 예시는 일시적 2주택 해당 없음)
- 매수 주택 가격대: [예: 4.10억]

## [Rules]

1. 전입신고·취득세·양도세 각 기한은 입력한 거래일과 그 날짜에 적용되는 공식 기준으로 확인하고, `기준일 → 법정 계산식 → 주말·공휴일 조정 전 명목 마감일 → 적용 법령의 기한 연장 규정에 따라 조정한 최종 마감일` 순서로 두 번 검산해 표로 제시하세요. 요일 계산은 보조 검산으로만 사용하고 공식 공휴일·휴무일 자료를 확인하세요. 공식 자료를 확인하지 못하면 명목 마감일은 제시하되 최종 마감일은 `확인 필요`로 표시하고, 휴일 기한을 임의로 이전 영업일로 앞당기지 마세요.
2. 전입신고는 주민등록 행정 절차, 취득세·양도세는 세무 신고라는 점을 구분해 작성
3. 각 절차의 필요 서류 리스트를 분리 제시
4. 양도세 비과세 검토 시 다음을 구분해 정리
   - 보유 기간
   - 거주 기간
   - 취득 시점 기준 조정대상지역 여부
   - 실제 양도일 기준 1세대 1주택 해당 여부
   - 추가 확인이 필요한 예외사항
5. 1세대 1주택 비과세는 "가능성 높음 / 조건부 / 확인 필요" 수준으로 정리하되, 단정 대신 판단 근거와 확인 필요 항목을 함께 제시
6. 일시적 2주택은 이번 케이스에 왜 적용되지 않는지 한 줄로 설명하고, 거래 순서가 달라지면 별도 검토 필요라고 표시
7. 취득세는 주택 수·가액·취득 시점에 따라 달라질 수 있으므로 "최신 기준 확인 필요"로 표기
8. 기한 경과 시 과태료·가산세 가능성만 설명하고, 구체 금액은 쓰지 말 것
9. 실제 제출 서류나 절차가 지자체·세무대리인·관할 세무서에 따라 달라질 수 있는 항목은 "확인 필요"라고 표시
10. 마지막에 "실제 신고 전에는 반드시 세무사 또는 관할 기관의 최신 기준을 확인하세요." 문구 포함

## [Output]

1. 법정·행정 기한 3종 캘린더(절차명 / 기준일 / 계산 방식 / 마감일 / 담당기관)
2. 전입신고 서류·절차
3. 취득세 신고·납부 서류·절차
4. 양도세 신고·납부 서류·절차
5. 1세대 1주택 비과세 검토 포인트
6. 이번 케이스의 추가 확인 포인트
7. 세무사 상담이 필요한 질문 5가지
8. 공식 근거표(절차 / 현재 적용 기준 / 법적 상태 / 시행일 / 경과조치 / 공식 출처 / 조회일)
9. ⚠️ 세율·공제·중과·감면·처분 기한은 변경될 수 있습니다. 정부안·입법예고안을 현행법으로 적용하지 말고, 실제 신고 전에는 반드시 세무사 또는 관할 기관의 기준일 현재 현행 기준을 확인하세요.
