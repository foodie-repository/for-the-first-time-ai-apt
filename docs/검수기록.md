# 검수 기록 (공개 전 필수 게이트)

프롬프트 본문의 책↔저장소 일치는 **자동화만으로 보장되지 않습니다**(원고 프롬프트가
최소 3가지 형식으로 섞여 있어, 추출 경계는 사람이 확인해야 함). 아래 게이트를 모두
통과해야 public 전환이 가능합니다.

## 1. 자동 검증 (tools/verify.py) — 매 커밋
- [ ] A1 파일명 정합: 책이 인용한 39개 파일명 ↔ 저장소 파일 (누락·초과 0)
- [ ] A3 변수 일관성: `[현재연도/월/일]`·`[대괄호]` 패턴, 떠도는 실제 날짜 0
- [ ] A4 인코딩·서식: UTF-8(BOM 없음)·개행 통일
- [ ] A5 민감정보: API 키·개인 실명/실주소/실재무수치 0
- [ ] B1 규제·세율 대조: 260808_수정내역서 / 260817_813대책_반영검토 와 1:1
- [ ] B2 프롬프트 간 수치 일관성: 동일 규제값이 여러 프롬프트에서 동일 표기

## 2. 사람 교정 (스테이징 → 확정) — 실습별 1:1 대조
각 실습 `.txt`를 책 지면과 한 문장씩 대조하고, 확정되면 `_staging/`에서 해당 챕터
폴더로 이동. 신뢰도 표기(HIGH/MED/LOW)는 `_staging/manifest.json` 참조.

| 실습 | 대조자 | 완료 |

| 10~15, 22~38 (계열 B) | | ☐ |
| 16~21 (계열 C, 연속형) | | ☐ |
| 지침 템플릿 | | ☐ |

## 3. 3인 교차 검수 + 감수
- [ ] 지피타쿠(이철로) — 정책·규제 수치 검증
- [ ] 푸디(정상기) — 프롬프트 로직·시점중립 설계
- [ ] 정케빈 — 총괄·최종 승인
- [ ] 세무사 — 세율·과세 표기 감수
