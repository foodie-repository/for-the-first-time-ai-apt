# 변수 표기 규칙

프롬프트에는 두 종류의 자리표시자가 있습니다.

## 1. 동적 변수 — AI가 조회일 기준으로 채움
- `[현재연도]` · `[현재월]` · `[현재일]`
- 그대로 두고 실행하면 AI가 "분석 기준일"을 오늘 날짜로 채웁니다.

## 2. 사용자 입력 변수 — 내 상황으로 직접 치환
- `[대괄호]` 안의 일반 항목 (예: `[연소득]`, `[가용 현금]`, `[관심 지역]`,
  `[무주택자 / 1주택자 / 다주택자]`)
- 붙여 넣기 전 또는 후에 내 조건으로 바꿉니다. 맞춤 지침에 이미 입력했다면 생략 가능.

## 3. ⚠️ 표시
- 실행 시점에 **변경 여부를 반드시 재확인**해야 하는 규제·세율 항목을 뜻합니다.
  ([`시점중립_안내.md`](시점중립_안내.md) 참조)

## 유의
- `202x년 x월 x일` 처럼 표기된 부분은 **실제 규제 기준일로 교체**하고 사용하세요.
- 프롬프트에 실제 연도·월이 하드코딩돼 보이면(예: 특정 대책 일자) 그대로 두되,
  현재 유효 여부를 확인하세요.
